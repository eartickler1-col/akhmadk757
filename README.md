Vice Cover Studio — an offline web app that turns a photo and a caption into multi-panel GTA-style cover art, with crop and position per panel, bold caption lettering, and a Vice City sunset / neon grade. Exports PNG in 1080×1080, 1080×1350 and 1920×1080. Photos are read on your own machine and never uploaded.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
